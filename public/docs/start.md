# 加入指南

三步进入 STCraft，开始你的冒险。

## 1. 启动游戏

打开 Minecraft **Java 版**客户端（推荐使用与服务端一致的版本，其他版本也可尝试）。

## 2. 添加服务器

进入「多人游戏」→「添加服务器」，在地址栏粘贴服务器地址并保存：

```
stcraft.cc
```

> 已配置 SRV 记录，直接填域名即可，无需端口号。

## 3. 注册并登录

首次进入服务器，请注册你的账号密码；之后每次进服登录即可。

```
/register 密码 密码
```

```
/login 密码
```

## 小贴士

- 服务器为**离线模式**，正版与离线玩家均可加入，注册密码保障账号安全。
- 请牢记你的密码，忘记密码请联系管理员协助找回。
- 进服后建议先输入 `/spawn` 回到出生点，熟悉环境后再出发冒险。
- 遇到问题可查看 [常见问题](faq)，或到 QQ 群 `786360709` 求助。
