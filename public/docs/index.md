# STCraft Wiki

STCraft 是一个 Minecraft **Java 版生存服务器**：领地保护、mcMMO 技能、玩家市场、每日签到，
正版与离线客户端均可加入，探索、建造、生存，一次满足。

- **服务器地址**：`stcraft.cc`
- **官网**：[www.stcraft.cc](https://www.stcraft.cc)
