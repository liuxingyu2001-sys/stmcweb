## 灵魂空间戒指

> **附加说明：** 灵魂戒指免费赠送 9 格子，可以无限堆叠，随用随取。共 6 页每页 45 格子，
> 500 星辰币可以解锁一页，可自动吸附物品。菜单新增赛季战令。

### 玩家使用

**打开空间**：手持「灵魂空间戒指」**右键**（空气或方块均可）打开个人空间，主手副手都支持。左键不会触发。

空间固定为多页 6 行 9 列布局，最下面一行是功能栏；每页可放 45 种物品。

### 空间内操作（点击空间物品）

| 操作 | 效果 |
| --- | --- |
| 左键 | 取 1 个进背包 |
| 右键 | 取 64 个进背包 |
| shift + 左键 | 背包全部物品放入空间 |
| shift + 右键 | 取最多 1728 个进背包（自动分组成原版上限） |

取走物品后，后续物品自动前移补位，空间始终紧凑、没有空洞。

### 放入物品（点击背包物品）

| 操作 | 效果 |
| --- | --- |
| 左键 | 放 1 个 |
| 右键 | 放 64 个 |
| shift + 左键 | 放一组（按物品原版上限） |
| shift + 右键 | 背包中同类物品全部放入 |

戒指不能被放入空间。

### 无限堆叠

同类物品在空间内自动合并，真实数量可超过原版上限（如 256、1024）。
GUI 中每个物品显示数量恒为 1（无角标），**鼠标悬停**时 Lore 显示真实数量。

### 功能栏按钮

| 槽位 | 按钮 | 说明 |
| --- | --- | --- |
| 45 | 上一页 | 第一页时隐藏 |
| 46 | 排序 | 左键切换按名称/数量，右键切换升序/降序；排序整个空间 |
| 47 | 自动拾取 | 点击切换开/关，图标与文字显示当前状态 |
| 48 | 关闭 | 关闭界面 |
| 49 | 存放 / 垃圾桶 | 左键：背包全部物品存入空间；右键：打开垃圾桶 |
| 50 | 页码 | 显示当前页/总页数与开放格子数 |
| 51 | 分类 | 点击循环切换分类（全部 → 分类1 → 分类2 → …） |
| 52 | 自定义按钮 | 可配置的指令按钮（默认黑玻璃） |
| 53 | 下一页 | 最后一页时隐藏 |

### 自动拾取

- **shift + 右键戒指**：切换自动拾取开关，戒指 Lore 实时显示「自动拾取：开启/关闭」。
- 开启后：挖掘方块掉落、击杀实体掉落会**瞬间**进入空间；走到掉落物旁边也会自动收取（兜底）。
- 空间放不下时，回退到普通背包；仍放不下则留在地面，不会丢失物品。

### 解锁格子

空间未解锁的格子显示为黑色玻璃板，悬停可见解锁花费与说明。**点击**未解锁格子：

1. 扣取点券 / 金币；
2. 解锁一批格子；
3. 执行奖励指令（如授予自动拾取权限）；
4. 执行自定义操作（如自动开启自动拾取）。

### 垃圾桶

右键 49 号按钮打开垃圾桶，垃圾桶显示空间内全部物品，删除的是**空间**里的物品：

| 操作 | 效果 |
| --- | --- |
| 左键 | 删除 1 个 |
| 右键 | 删除 64 个 |
| shift + 左键 | 删除 640 个 |
| shift + 右键 | 全部删除 |

垃圾桶支持翻页：每页显示 45 种物品，功能行 45 上一页、46 页码、52 下一页、53 返回空间界面（不是关闭）。

## 星露谷种植

**体验星露谷物语般的种植乐趣！** 种植作物、收获高品质果实、解锁更多品种。

### 种植玩法

- 在商店购买种子，右键耕地即可种植
- 每个作物有独特的生长周期和最佳种植季节
- 使用洒水壶或洒水器自动浇水，提高效率
- 骨粉可以加速生长

### 品质系统

收获时有概率获得不同品质的作物：

- **普通品质** —— 基础收获
- **银星品质** —— 稀有掉落，售价更高
- **金星品质** —— 超稀有，最高售价

### 可种植作物

| 作物 | 季节 | 特点 |
| --- | --- | --- |
| 🍅 番茄 | 春季 | 可产出巨型番茄 |
| 🍍 菠萝 | 夏季 | 可产出巨型菠萝 |
| 🥬 卷心菜 | 春/夏 | 可产出巨型卷心菜 |
| 🌽 玉米 | 夏/秋 | 基础作物 |
| 🍺 啤酒花 | 夏季 | 产量高，自动重生 |
| 🧄 大蒜 | 四季 | 产量稳定 |
| 🌶️ 辣椒 | 春/秋 | 产量高，可自动重生 |
| 🍇 葡萄 | 春/夏/秋 | 可自动重生 |
| 🍆 茄子 | 夏/秋 | 基础作物 |
| 🥬 白菜 | 春/夏/秋 | 基础作物 |
| 🐉 火龙果 | 春/夏/秋 | 稀有作物，可自动重生 |
| 🧧 摇钱树 | 冬季 | 冬季限定，掉落红包 |

### 农场工具

- **洒水壶** —— 4 个等级，手动浇水
- **洒水器** —— 3 个等级，自动浇灌周围作物
