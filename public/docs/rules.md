# 服务器规则

良好的游戏环境需要大家共同维护。

## 六条红线

1. **禁止作弊**：禁止使用外挂、作弊端、透视材质、连点器等一切破坏公平的辅助工具，违者封禁处理。
2. **禁止破坏他人**：禁止破坏、偷窃他人建筑与物品，禁止恶意圈地占地、设置陷阱害人。
3. **禁止欺诈**：禁止欺诈交易，贵重物品交易请使用玩家市场，线下交易风险自负。
4. **文明聊天**：聊天频道禁止刷屏、辱骂、引战、发布违规内容及任何形式的广告。
5. **禁止恶意装置**：禁止私自建造高频红石、刷物机等严重影响服务器性能的装置。
6. **尊重管理**：尊重管理员的管理决定，如有异议请通过官方 QQ 群或游戏内向管理员申诉。

> 违规行为会根据情节轻重给予警告、临时封禁或永久封禁处理。
> 处罚申诉请到 QQ 群 `786360709` 联系管理员。
